# Power BI Report Guide

Power BI Desktop is Windows-only, so no `.pbix` file is built in this
(Linux) environment. This guide documents the data model, DAX measures, and
report pages so the dashboard can be reproduced in Power BI Desktop from the
CSVs and SQLite database already generated by the `src/` scripts.

## Data sources

Run these first, in order, to produce the files this report imports:

```
python src/generate_sales_data.py
python src/load_to_sql.py
python src/forecasting.py
python src/segmentation.py
python src/export_for_powerbi.py
```

| File | Role |
| --- | --- |
| `data/processed/sales.db` | SQLite DB with `customers`, `products`, `orders`, `order_items` tables (schema in `sql/schema.sql`) |
| `data/processed/powerbi_forecast.csv` | Monthly actual + forecast revenue (`month`, `revenue`, `type`) |
| `data/processed/powerbi_segments.csv` | Per-customer RFM segment (`customer_id`, `recency_days`, `frequency`, `monetary`, `segment`) |

In Power BI Desktop: **Get Data → SQLite database** for `sales.db` (import
`customers`, `products`, `orders`, `order_items`), and **Get Data → Text/CSV**
for the two `powerbi_*.csv` files.

## Data model (relationships)

```
customers[customer_id] 1---* orders[customer_id]
orders[order_id]       1---* order_items[order_id]
products[product_id]   1---* order_items[product_id]
customers[customer_id] 1---1 powerbi_segments[customer_id]
```

Add a standalone **Date** table (Power Query `CalendarAuto()` or a calculated
table) marked as the model's date table, related to `orders[order_date]`, so
the built-in time-intelligence DAX functions work correctly.

## DAX measures

```dax
Total Revenue = SUM(order_items[net_amount])

Total Orders = DISTINCTCOUNT(order_items[order_id])

Average Order Value = DIVIDE([Total Revenue], [Total Orders])

Unique Customers = DISTINCTCOUNT(orders[customer_id])

Total Discount Given = SUM(order_items[discount_amount])

Gross Revenue = SUM(order_items[gross_amount])

Discount Rate % = DIVIDE([Total Discount Given], [Gross Revenue])

Revenue MoM % =
VAR CurrentRevenue = [Total Revenue]
VAR PriorRevenue =
    CALCULATE([Total Revenue], DATEADD('Date'[Date], -1, MONTH))
RETURN
    DIVIDE(CurrentRevenue - PriorRevenue, PriorRevenue)

Forecast Revenue = SUM(powerbi_forecast[revenue])

Champions Customers =
    CALCULATE(
        DISTINCTCOUNT(powerbi_segments[customer_id]),
        powerbi_segments[segment] = "Champions"
    )
```

## Report pages

1. **Executive Overview** — KPI cards for Total Revenue, Total Orders,
   Average Order Value, Unique Customers; a line chart of monthly revenue
   with `Revenue MoM %` on tooltips; a bar chart of revenue by region.
2. **Product & Category Performance** — matrix of revenue/units by category
   and product (top N filter), plus `Discount Rate %` by category.
3. **Revenue Forecast** — line chart built from `powerbi_forecast.csv`,
   split by the `type` column (actual vs. forecast) so the projected months
   render as a dashed/distinct series.
4. **Customer Segmentation (RFM)** — donut chart of customer count by
   `segment`, scatter plot of `frequency` vs. `monetary` colored by
   `segment`, and a table of top customers per segment.

Slicers for **Region**, **Category**, and **Date range** should be placed on
every page (sync slicers across pages via Format → Edit interactions /
Slicer sync pane).
